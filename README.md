**# Nepo-Client-V1.0

Nepo Launcher is an Android application designed to run Minecraft: Java Edition on mobile devices. Built upon the foundational work of the open-source community, it provides a streamlined way to experience the Java version of the game, complete with modding and skin support, directly on your phone.

Latest Release: v0.2.0-alpha

Features

Based on the release notes for v0.2.0-alpha, Nepo Launcher includes the following capabilities:

· Minecraft Java Edition Support: Play the Java Edition of Minecraft on your Android device.
· Integrated Mods System: Install and manage mods directly within the launcher, eliminating the need to browse external websites .
· Skin Management: A dedicated system to manage and apply custom skins.
· Update Logs: View changelogs for every Minecraft update.
· Clean UI/UX: A managed and easy-to-understand interface.
· Optimized Performance: Focused on high optimization for mobile gameplay.

Installation

1. Navigate to the Releases page.
2. Download the latest .apk file (v0.2.0-alpha).
3. Enable "Install from Unknown Sources" in your Android device settings if prompted.
4. Install the APK and launch the app.

Note on Requirements: Running Minecraft Java Edition on Android is resource-intensive. For a smooth experience, a device with at least 4 GB of RAM is generally recommended, though performance will vary based on your specific hardware and the Minecraft version you choose to run .
